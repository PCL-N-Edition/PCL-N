# 预检修复产品接入

修复动作通过既有 sealed machine.capabilities.remediation 命令分派。平台界面将完整实例目录
作为作用域，涉及修改的动作先确认；Java 文件选择返回前保留最初实例身份，不把结果应用给
后来切换的实例。内存修复写实例覆盖，不修改全局值。

Composition 在激活前一次性绑定 MinecraftRuntime 所有的 Java locator/installer/文件补全器
及 MinecraftInstallRuntime 的安装器。修复处理器未绑定时不可执行，禁止创建第二套后台
安装器以绕过既有 Stop/Recover 和退出保护。服务不依赖 UI 或从容器解析服务。

Java 修复复用启动用的要求解析、检查真实运行时并保存实例选择；下载使用可恢复安装器。
文件补全在根目录独占租约中运行，活动游戏阻止共享文件修复。版本/Loader 修复使用既有
修改安装事务，ForceReinstall 显式绕过“选择未变化”的短路并随安装意图持久保存；保留其余
已选组件。损坏到无法读取清单/识别原组件的实例拒绝猜测重装。

本单元不把模组冲突自动删除、依赖自动选择、高性能 GPU 切换、实例移动或 Loader 切换
标记完成；这些需要各自的候选与确认流程。
