## 本轮正确性修复

- 类路径按规范化文件路径去重，保留首项顺序，避免 NeoForge BootstrapLauncher 因重复依赖 JAR 的 `Duplicate key` 提前退出。异常摘要优先展示异常首行和原因链，脱敏输出写入本地启动日志。

- 旧实例缺失或显式为 null 的 `corePatchSha256` 归一为空记录；启动文件补全按未应用补丁继续，不再触发空引用。有效补丁仍须核对本实例核心路径与 SHA-256。

- ZIP 清单先做有界读取再解析；覆盖文件按实际字节扣除同一预算，短读和超长均失败。
- JAR 安装器清单同样先做有界读取；核心补丁合并的原核心与补丁条目共用 2 GiB 实际展开预算，单项不超过 512 MiB，实际长度不符时保留原核心并清理临时产物。
- 任务状态在业务锁内编号并入队，单一发布者在锁外顺序发布列表和摘要；观察者重入只入队。
- 文件夹导入预检并再次校验继承链，缺失父版本、循环和无效清单不提交。
- MinecraftProcessSnapshot 携带实例目录；JAR 修改不再误拦其他根目录的同名实例。

下一批建议优先：窗口合成与输入映射 → 真正 Jvm.Host 启动验证 → 受签名保护的自动更新事务。
Patch 改写器独立推进契约设计与编译器验证，不能以空 Patch.point 调用宣布完成。
