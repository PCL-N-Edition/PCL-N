## 本轮正确性修复

- ZIP 清单先做有界读取再解析；覆盖文件按实际字节扣除同一预算，短读和超长均失败。
- 任务状态在业务锁内编号并入队，单一发布者在锁外顺序发布列表和摘要；观察者重入只入队。
- 文件夹导入预检并再次校验继承链，缺失父版本、循环和无效清单不提交。
- MinecraftProcessSnapshot 携带实例目录；JAR 修改不再误拦其他根目录的同名实例。

下一批建议优先：窗口合成与输入映射 → 真正 Jvm.Host 启动验证 → 受签名保护的自动更新事务。
Patch 改写器独立推进契约设计与编译器验证，不能以空 Patch.point 调用宣布完成。
