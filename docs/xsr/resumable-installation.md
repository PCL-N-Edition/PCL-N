# 可恢复下载与安装

此文档记录 Alpha 5 新增要求；当前安装/退出路径尚未实现这些保证。

正常退出时，只要存在未完成的下载或安装，必须先暂停关闭流程。新安装提供“取消 / 暂停”，
修改现有版本提供“回滚 / 暂停”。暂停须先将计划和检查点写入磁盘、停止工作者并保留有效
数据，然后才关闭。取消清理本任务独占暂存；修改回滚依照原内容备份撤回，不能删除用户
配置或共享缓存。混合任务退出要明确每类任务的处置，撤回失败时不能声称已安全完成。

下次启动自动发现并继续暂停及异常中断任务，不能依赖正常退出回调才保存检查点。
任务状态、固定版本/加载器选择、已验证产物、当前阶段、实例完整身份及修改前备份持久化。
重新启动不能从 UI 状态或当前选中的目录猜测目标。恢复记录是非可信输入，必须重新验证
路径范围、版本/下载/本地安装器身份与实际文件内容；活动游戏、另一恢复任务和目录冲突
必须阻止相互覆盖。同一持久任务不能因重复启动或任务中心重新注册执行两次。

阶段变更采用“写入意图 → 执行 → 验证 → 提交检查点”。完成步骤复用已验证文件；未完成
的外部安装器步骤在隔离暂存目录中重做，不能直接重放对活版本的任意副作用。网络断点
只在服务端支持 Range、实体身份和大小一致时续传，否则仅重下未完成文件，不丢弃已完成
且通过摘要验证的文件。暂停与用户取消不是同一个 CancellationToken 结果。

修改事务保留原版本和设置直到最终提交；恢复快照的文件/设置补偿机制提供基础，但
安装步骤检查点、安装专用事务、退出协调与启动自动恢复仍需独立接入。不得用内存任务
中心状态、普通重试或只有 prepared 标记替代完整实现。

验收覆盖：退出两类对话、暂停后重启、下载中强制终止、各安装/修改阶段强制终止、
重复恢复、过期/篡改记录、断点不支持/实体变更、取消和修改回滚、失败补偿、共享文件保留、
跨根同名实例与 AOT/trim。需有独立进程终止/重启测试，不能只用同一实例的单元重试代替。

## 已实现的发布阶段（2026-09-25）

修改版本已用持久发布事务替换内存回滚列表。日志绑定根目录、暂存目录和实例；发布前
保存并校验所有原内容与目标内容，flush 后原子写入计划与进度。每项写入前保存意图，
实例清单最后提交。重新打开日志可继续发布，或按逆序撤回；当前内容不是预期原值/目标值
时停止并保留备份，不能覆盖第三方后续修改。所有条目都有路径范围、文件/总量限制和
实际长度/摘要校验；不可删除存档等目录。暂存仅在发布/撤回完成后清理，补偿失败保留。

回归使用独立子进程，在第一个真实活文件发布后强制结束进程，再由新打开的事务分别
继续发布和回滚，并验证重复调用、外部修改保护、相同组件保留、非法目标拒绝。此验收
只覆盖文件发布阶段；尚未覆盖下载中断、退出选择、启动自动发现、元数据固定、加载器
子步骤检查点、安装改名阶段、整合包和 Java 安装。内部 Apply/Undo 能力不是用户已可用
的暂停/自动恢复功能。调用方仍须提供根目录互斥和活动游戏检查；同账户恶意进程的持续
竞态隔离不属于此日志的保证。
