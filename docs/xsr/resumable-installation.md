# 可恢复下载与安装

## 用户行为

存在活动 Minecraft、整合包或 Java 安装时，原生关闭按钮、Alt+F4、系统关闭请求共用关闭守卫。
新安装可“取消安装并退出 / 暂停并退出 / 留在启动器”；修改任务提供回滚，混合任务明确显示
“取消安装／回滚并退出”。暂停等待持久计划落盘，停止并等待工作者，再关闭窗口。
撤回失败不关闭窗口，保留记录并允许重试。停止开始后关闭新任务准入，避免关闭过程中新增任务。

下次启动自动扫描已配置游戏根目录和 composition 固定的 Java 目录，继续暂停或异常中断任务。
恢复不依赖当前 UI 选择，也不会因恢复 Java 下载而自动启动游戏。任务中心 Paused 仅表示本次
工作者结束，磁盘任务仍可恢复；清除任务卡片不取消磁盘任务。

## 身份和持久化

- 新安装：`.nexa-install-jobs/<GUID>/.task`。
- 版本修改：`.nexa-modify/<GUID>/.task`，改名子事务在同一任务的 `.rename`。
- 整合包：`.nexa-pack-jobs/<GUID>`。
- Java：运行时根目录下 `.nexa-java-jobs/<GUID>`。

记录固定根目录、实例、版本、加载器、附属组件、隔离选择、本地安装器身份等。JSON 使用
source-generated 元数据，有读取预算和路径/类型/摘要验证。写入采用临时文件、flush(true)
和原子替换。任务文件锁阻止重复执行；恢复修改还持根目录独占租约并检查活动游戏进程。
记录损坏、目录冲突、后续文件修改或锁冲突必须停止，不能覆盖为一个新的任务。

## 下载和加载器

Mojang 清单、资产索引、加载器 profile 和附属 Mod 的合并下载记录缓存于任务私有目录，绑定
请求身份及内容摘要。恢复不重新查询同一 Modrinth/CurseForge 选择。已完成文件重新验证后复用；
缺少可信摘要的半成品不能仅靠大小认定完成。网络续传仅在下载引擎确认 Range/实体身份时使用，
不支持时重下未完成文件，不保证每个来源都能按字节断点续传。

外部加载器安装器在执行前固定实际 SHA-256 与缓存。没有提供方摘要时不把本地摘要冒充签名。
每次处理器重做使用隔离 scratch，旧 scratch 不参与发布。处理器由宿主专用无界面 worker 托管，
使用有界二进制启动请求和 stdin 管道租约；宿主退出后 worker 终止并等待安装器进程树。
此机制不使用 Sidecar 同步调用或反射分发。

## 文件发布和修改回滚

所有产物先暂存；发布前记录原内容和目标内容。每项活文件写入前保存意图，实例清单最后提交。
恢复校验已完成前缀，再继续尚未完成的写入。回滚按逆序补偿，当前内容必须等于记录的原值或
目标值，否则保留备份并报告冲突。共享缓存及用户配置不得按“取消安装”任意删除。

纯改名也创建持久修改任务。目录移动携带随机事务归属标记；清单引用、核心文件名和实例设置
各有可重放步骤。设置以前/后值比较及 revision CAS 提交，不覆盖后续修改。组件发布记录保留到
改名结束；联合任务未完成时，取消先逆序撤回改名，再撤回组件发布。改名完成后才写任务终态。
nullable 二进制前值使用 JSON metadata 模式，严格区分“不存在”和“空文件”。

## 整合包

固定源归档及 SHA-256、用户选择和解析后的下载文件身份。即使外部原归档被移走，也能使用
已缓存且重新校验的源继续。共享依赖只添加或复用相同内容。覆盖文件遵守实际展开预算。
实例完整准备后记录发布文件清单及摘要，再原子移动整个实例目录。移动后丢失完成标记时，
重新校验发布内容再确认完成；已经提交的实例不被迟到的取消删除。

## Java

固定组件请求与文件计划，逐文件验证后在 payload 中准备运行时。发布组件目录前保留旧目录，
根据 payload/previous/目标及标记恢复中断的目录移动。取消意图先落盘，再恢复旧目录。
下载限制落实到流的实际长度，超长或短读不发布；已完整的运行时直接复用。
`JavaInstallRecoverCommand` / `JavaInstallStopCommand` 为 sealed XSR 命令，根目录由 composition
提供。Java 卡片参加统一退出协调，嵌套加载器安装不向活目录发布 Java 私有恢复记录。

## 终态与清理

Pending、RollbackRequested、Completed、RolledBack 不允许终态复活。退出处置包含当前工作者和
尚未开始的排队任务。取消/回滚成功后清理任务专属暂存和下载，保留小型身份、状态记录；完成的
Java/整合包同样清理私有缓存。清理只接受专用目录下的 GUID 任务，拒绝符号链接，不递归删除
游戏根目录。清理因文件占用失败可以保留残余缓存，不能把成功回滚误报成失败。

## 验证与边界

回归覆盖独立进程在下载、活文件发布期间被强制终止后恢复；真实 worker 所有者被终止后的
子进程回收；准备/发布/回滚重入、队列处置、篡改和锁冲突；Java 暂停与取消；整合包失去外部
源归档后的恢复；改名各操作边界中断、联合修改回滚、大小写改名、实例设置与依赖引用。
Desktop 测试覆盖关闭守卫和仅 Java 活动时等待停止。CI 继续执行架构检查、trim 与 NativeAOT
Desktop shell smoke。控制器测试不等同于在三个操作系统上人工点击窗口的验收。

外部安装器内部步骤不做指令级 checkpoint，而是在隔离目录重做未完成处理器步骤；这避免恢复
无法证明幂等的第三方副作用。损坏记录、外部变化或源在首次缓存完成前消失会明确失败并保留记录，
不以丢弃证据或替换用户文件的方式强行完成。
