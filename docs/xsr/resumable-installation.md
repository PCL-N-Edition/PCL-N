# 可恢复下载与安装

此文档记录 Alpha 5 的目标契约与分阶段实现。当前覆盖范围和限制见文末“退出协调命令”。

正常退出时，只要存在未完成的下载或安装，必须先暂停关闭流程。新安装提供“取消 / 暂停”，
修改现有版本提供“回滚 / 暂停”。暂停须先将计划和检查点写入磁盘、停止工作者并保留有效
数据，然后才关闭。取消清理本任务独占暂存；修改回滚依照原内容备份撤回，不能删除用户
配置或共享缓存。混合任务退出要明确每类任务的处置，撤回失败时不能声称已安全完成。

下次启动自动发现并继续暂停及异常中断任务，不能依赖正常退出回调才保存检查点。
任务状态、固定版本/加载器选择、已验证产物、当前阶段、实例完整身份及修改前备份持久化。
重新启动不能从 UI 状态或当前选中的目录猜测目标。恢复记录是非可信输入，必须重新验证
路径范围、版本/下载/本地安装器身份与实际文件内容；活动游戏、另一恢复任务和目录冲突
必须阻止相互覆盖。同一持久任务不能因重复启动或任务中心重新注册执行两次。

阶段变更采用“写入意图 → 执行 → 验证 → 提交检查点”。完成步骤复用已验证文件；未完成
的外部安装器步骤在隔离暂存目录中重做，不能直接重放对活版本的任意副作用。网络断点
只在服务端支持 Range、实体身份和大小一致时续传，否则仅重下未完成文件，不丢弃已完成
且通过摘要验证的文件。暂停与用户取消不是同一个 CancellationToken 结果。

修改事务保留原版本和设置直到最终提交；恢复快照的文件/设置补偿机制提供基础，但
安装步骤检查点、安装专用事务、退出协调与启动自动恢复仍需独立接入。不得用内存任务
中心状态、普通重试或只有 prepared 标记替代完整实现。

验收覆盖：退出两类对话、暂停后重启、下载中强制终止、各安装/修改阶段强制终止、
重复恢复、过期/篡改记录、断点不支持/实体变更、取消和修改回滚、失败补偿、共享文件保留、
跨根同名实例与 AOT/trim。需有独立进程终止/重启测试，不能只用同一实例的单元重试代替。

## 已实现的发布阶段（2026-09-25）

修改版本已用持久发布事务替换内存回滚列表。日志绑定根目录、暂存目录和实例；发布前
保存并校验所有原内容与目标内容，flush 后原子写入计划与进度。每项写入前保存意图，
实例清单最后提交。重新打开日志可继续发布，或按逆序撤回；当前内容不是预期原值/目标值
时停止并保留备份，不能覆盖第三方后续修改。所有条目都有路径范围、文件/总量限制和
实际长度/摘要校验；不可删除存档等目录。暂存仅在发布/撤回完成后清理，补偿失败保留。

回归使用独立子进程，在第一个真实活文件发布后强制结束进程，再由新打开的事务分别
继续发布和回滚，并验证重复调用、外部修改保护、相同组件保留、非法目标拒绝。此验收
只覆盖文件发布阶段；尚未覆盖下载中断、退出选择、启动自动发现、元数据固定、加载器
子步骤检查点、安装改名阶段、整合包和 Java 安装。内部 Apply/Undo 能力不是用户已可用
的暂停/自动恢复功能。调用方仍须提供根目录互斥和活动游戏检查；同账户恶意进程的持续
竞态隔离不属于此日志的保证。
## 已实现的修改任务计划

修改任务在下载/生成文件前，将任务 ID、原始根目录、实例名、Minecraft/加载器/附属组件
选择、安装方式、原清单指纹、本地安装器身份和可选改名目标写入 `.task/plan.json`。
记录采用版本化 source-generated JSON、大小限制、flush 与不可覆盖的原子发布；读取
重新校验目录归属、版本引用、组件数量和下载/本地文件身份。调用者列表的后续修改
不会改变已保存计划。任务记录不进入向 Minecraft 根目录发布的文件集合。

已验证独立子进程被终止后能从原目录读取这些固定选择；恢复不依赖当前 UI 选择。
此阶段仅固定用户意图，不代表远端元数据已冻结，也不等于完整安装检查点。准备阶段
重用、固定元数据/下载身份、自动发现、退出协调和安装改名的恢复仍未接入。
## 修改安装的持久元数据

完整重装路径现在通过任务内缓存读取 Vanilla 清单、profile 型加载器清单和资源索引。
缓存键绑定完整请求，记录保存请求身份和内容 SHA-256；先 flush 再发布，不覆盖已有记录。
每次返回独立 JSON 对象，安装流程修改清单不会改变已冻结的原始数据。损坏记录明确失败，
不回退到重新联网获取。单项限制 16 MiB，任务最多 32 项/64 MiB；跨实例/进程的文件锁
串行化发布，等待可取消且有时间上限。缓存文件只保存在 `.task`，不发布到游戏目录。

回归覆盖重新创建源后复用旧内容、调用方修改隔离、损坏/超大记录拒绝、并发等待取消。
processor 型加载器安装器自身的元数据尚未冻结；新安装、下载片段
身份、暂停/启动自动续作仍未接入。此缓存不代表这些未完成项目已经具备恢复保证。
发布事务提交 ee34383e 的 XSR CI 36129761225 已完整通过，包含 NativeAOT Desktop/首次引导、trim 分析和裁剪后两项冒烟；不涵盖后续任务计划和持久元数据提交。

## 附属组件下载记录

完整重装和仅修改组件两条路径均在下载前保存所选组件的合并下载记录，绑定 Minecraft
版本、组件类型和组件版本。来源列表顺序、URL、文件名、声明大小和提供方摘要在同一
任务内保持不变；恢复读取不会重新查询 Modrinth/CurseForge 目录。记录复用元数据缓存
的原子发布、大小限制和完整性检查，并限制下载数量、路径、HTTPS 和摘要格式。

回归覆盖双源记录持久复用、调用方后续修改隔离、无效身份拒绝及失败后重新解析。
提供方未给摘要时不会伪造已验证身份；产物实际摘要检查点、processor 安装器元数据、
退出选择与自动恢复仍待接入。暂不宣称所有下载都已经支持断点续传。
## 修改恢复执行约定

恢复执行器只接受根目录和持久任务 ID，再从对应目录读取原计划。根目录独占租约、
活动游戏检查和任务文件锁必须先于续作；不能使用 UI 的当前选择重新构造安装命令。
已有发布日志时继续文件发布，不重新运行加载器或按旧指纹解析部分写入的活版本。
没有发布记录时复用原暂存目录、固定计划与元数据重新准备；存在不完整发布记录则
保留并报告错误，不把它当作全新任务覆盖。恢复失败或取消保留暂存，供后续处理。
发布恢复先验证已完成前缀仍等于目标内容；committed 也须检查实际文件，防止中断后
外部改动被静默当作成功。改名事务与自动发现尚未接入时不得冒充支持该恢复场景。
内部修改恢复执行器现已实现上述两阶段分流：准备阶段复用原目录，发布阶段直接续写日志。
正常修改和恢复执行都持有任务文件锁，避免同一持久任务同时执行；恢复另持根目录独占
租约，并检查当前进程注册表中的活动游戏。恢复成功的暂存仍保留，终态清理/自动发现
后续接入。回归已通过服务入口继续被强制终止的发布事务、继续未发布的准备任务、重复
恢复不再请求版本元数据、任务锁冲突、活动游戏阻止修改，以及提交后外部修改拒绝。

该执行器仍为内部路径，尚未接启动自动发现或退出选择；processor 外部子进程在主进程
异常退出后的所有权回收、固定安装器身份、改名恢复与整合包/Java 安装均未完成。
不能据此声称真实加载器安装器被杀进程后的所有场景已通过验收。
## 修改任务终态与撤回意图

终态单独持久保存并绑定任务 ID。继续执行只接受尚未终止的任务；已完成任务不得作为
未完成任务回滚，已回滚任务不得重新执行。用户撤回先保存 rollback-requested 意图，再
逆序撤回发布日志，最后保存 rolled-back。中断在撤回中间时保留原意图，后续只继续撤回，
不能误走安装续作。完成标记必须在任务中心发布成功之前落盘。暂存清理及启动发现可据
终态决定是否显示任务，但不能以清除内存任务代替写入终态。
内部执行器现已保存完成/撤回终态并提供撤回入口。撤回遇到外部文件冲突时保留
rollback-requested 与备份，阻止误续装；冲突解除后可重复继续撤回。文件已提交但任务
终态缺失时，先校验发布内容并补写完成状态，再拒绝未完成任务撤回。恢复任务的成功
通知在终态写入后发布，回滚任务不提供会造成二次取消的任务中心取消按钮。

新增回归覆盖强制终止后的服务级回滚、冲突后保留撤回意图、终态不可复活、其他任务
状态拒绝，以及提交与终态之间的中断窗口。正常退出的暂停选择、终态目录清理和启动
自动发现仍待接入；本轮没有增加对这些未完成项的完成声明。
## 有界发现与批量恢复路由

密封命令 minecraft.install.recovery 接收已注册根目录列表（最多 64 个），在指定根的
.nexa-modify 下发现任务，不递归搜索磁盘。每批至多检查 256 个目录；未知目录保留，
终态任务跳过，损坏任务逐项报告，其他任务继续。待回滚只进入回滚路径；待继续才进入
安装恢复。processor 型加载器在尚未发布时因子进程所有权恢复未完成，明确报告暂不支持
并保留记录，不冒险同时运行两份安装器。桌面启动生命周期通过此路由发起后台恢复。
桌面现已在真实 GUI 启动前，从 library 状态读取已注册根目录并后台派发恢复命令；
headless shell/OOBE 验证不发起恢复。GUI 生命周期结束后，先取消并等待这次派发结束，
再停止应用服务；取消的恢复任务保留暂存供后续继续。测试覆盖根目录快照隔离、后台
派发生命周期与取消等待，批量扫描中的坏记录隔离、重复根、终态跳过和待回滚分流。

自动恢复现已覆盖新安装与修改；用户正常退出时的选择弹窗、processor 准备阶段
外部进程回收、改名恢复、Java/整合包恢复与终态空间回收仍未完成。暂停按钮尚未实现，
不能将启动恢复生命周期的取消解释为已完成用户要求的完整暂停交互。
自动恢复卡片暂不提供通用取消按钮，避免把会在下次启动继续的暂停误标为取消；后续接入明确的暂停/回滚选择。关闭生命周期仍能取消其工作者并保留记录。

## 新安装隔离与恢复

新安装采用 .nexa-install-jobs/<任务 ID> 暂存，沿用固定计划、元数据和发布日志。原版本
目录在验证完成前不发布；已存在的同名版本拒绝覆盖，修改必须走修改路径。固定计划
绑定新安装/修改目录种类，禁止跨种类解释记录。新安装复用已验证的共享文件，但不以
存在即完成；发布顺序仍为版本清单最后，取消仅撤回该事务的活文件改动。
新安装的恢复也由同一个受生命周期约束的批量路由发现，processor 准备阶段限制仍保留。
新安装现已接入隔离准备与启动恢复。独立子进程测试在带摘要的客户端文件下载完成后强制终止，
再通过批量恢复路由完成安装，验证固定元数据复用、已校验文件不重复下载、终态跳过及
同名版本拒绝覆盖。原有安装、组件修改和加载器回归继续验证发布行为。

没有提供方摘要的文件尚缺完成产物收据，恢复时不会按存在/大小直接复用；改为重新
下载。DownloadRequest.AllowResume=false 时每个来源从零开始，并禁用分段，防止把
身份不明的遗留片段拼接到新响应。已知摘要的文件仍按原摘要校验与复用。新回归验证
遗留临时文件和来源失败后的第二次请求都从零开始。无摘要产物的持久完成收据仍待实现。
从零下载路径还会拒绝非零响应起点、超出声明长度以及提前结束的响应，只有完整响应才提交。

## 暂停的任务中心投影

暂停是本次工作者的终态，但不是持久安装任务的完成或取消。任务中心新增 Paused，
保留当时进度和步骤、停止速度统计并退出活动计数。恢复工作者因宿主关闭而停止时
发布 Paused；磁盘计划继续为 Pending，下次启动可继续。任务中心清除卡片不删除
持久计划。正常安装的退出协调与用户暂停路由仍单独接入，不能调用 Canceled 代替。

## 退出协调命令

新增 sealed command minecraft.install.stop：先关闭本服务的任务准入，再停止并等待所有
已登记安装工作者。Pause 保留持久计划及发布进度；Cancel 撤回未提交任务，恢复中的
修改也需执行持久回滚。任何撤回失败都返回失败，窗口不得关闭。暂停目前拒绝带改名
或 processor 准备步骤的任务，不能以缺少恢复支持的任务冒充可暂停任务。
现已接入原版/profile 安装和修改的停止命令、活动任务准入封锁、工作者结束等待、
原任务暂停保留与恢复任务撤回。暂停逐个等待各任务写入计划再取消，避免多个任务
争用根目录锁时互相等待。原生关闭按钮、Alt+F4 和系统关闭请求走同一关闭守卫；
弹窗可留在应用、暂停并退出或取消/回滚并退出，停止失败时不批准关闭。
此入口仅处理正在执行的普通安装/修改及恢复任务；排队尚未开始恢复的磁盘任务、
Java/整合包独立任务、processor 暂停与改名暂停仍未覆盖，不能宣称全部完成。

## 排队恢复任务的退出处置

恢复服务在扫描前固定并登记整批根目录，同时发布排队任务卡片。退出时先封锁新任务，
停止活动工作者，再等待扫描批次退出；取消/回滚随后扫描这些根目录的两个专用任务目录，
撤回尚未执行的 Pending / RollbackRequested 任务。终态跳过，未知名称目录保留；损坏记录
或超过检查预算必须返回失败，不能批准安全退出。扫描和回滚均在后台进行。
撤回失败后保留关闭守卫，同时允许重试撤回；准入保持关闭，避免重试与新安装竞争。
缺失终态标记但文件发布已经提交的任务，会先校验并修复 Completed，取消批次随后跳过。

## 外部安装器进程托管

加载器安装器通过同一宿主的专用无界面 worker 模式运行。宿主使用匿名 stdin 管道传入
有界二进制启动参数，并将管道保持打开作为租约。worker 监视管道 EOF；宿主异常退出
或租约丢失时终止安装器进程树并等待退出。正常取消也终止并等待整棵树。
worker 在任何产品初始化前分流，不使用 UI、反射分发或同步 Sidecar IPC。安装器输出
仍由父进程有界收集。每次重做使用新的隔离工作目录，旧工作目录不进入文件发布集合。
安装器已在运行前以 SHA-256 收据固定到任务私有缓存；恢复先校验原缓存，不重新获取
同一版本的远端安装器。缓存损坏明确失败。没有提供方摘要的旧安装器也记录实际身份，
但不将本地摘要冒充提供方签名。每次处理器重做使用新的隔离目录，遗留 scratch 排除发布。

## Java 运行时恢复契约

Java 下载在运行时根目录的 .nexa-java-jobs/<GUID> 保存请求及固定文件计划，payload 中
校验所有文件后才发布组件目录。目录发布保留旧组件备份，崩溃后根据 payload/previous/
目标及完成标记继续提交；不可按文件存在推断成功。暂停保留记录，取消恢复旧组件；
未知或篡改路径/摘要、活动任务锁冲突均停止。启动恢复只完成 Java 获取，不自动启动游戏。

sealed JavaInstallRecoverCommand / JavaInstallStopCommand 由 Minecraft composition 注册，
恢复根目录由 composition 固定。Java 下载卡片参与统一关闭守卫，关闭前等待 Java 和
Minecraft 两组工作者安全停止。取消意图先持久化，再恢复旧目录；取消中断后继续撤回。
文件流以声明长度限制实际读取，超长或短读均拒绝发布。已完整且逐文件校验通过的运行时
直接复用，不创建重复组件备份；嵌套加载器安装不发布 Java 私有任务记录。

## 整合包恢复契约

整合包在 .nexa-pack-jobs/<GUID> 固定源归档 SHA-256、用户选择和解析后的下载文件身份。
恢复复用归档、固定元数据及校验通过的下载；不重新选择远端 CurseForge 文件。
共享依赖只添加或复用相同内容。实例完整准备后记录文件清单及摘要，再原子移动实例目录。
移动后丢失完成标记时校验发布清单再确认完成；已提交实例不因迟到的取消被删除。
暂停保留任务，取消先写取消意图并阻止恢复。专用目录参与统一启动扫描与退出协调。

## 修改后改名的联合恢复

修改任务保留发布记录至改名结束。改名记录固定原/新目录、清单前后内容、核心文件移动和
实例设置的前后投影，每一步先记录意图再执行。恢复可重做尚未完成的步骤；撤回按逆序
恢复改名，再恢复组件发布。设置使用当前值与前/后投影比较，不覆盖用户后续更改。
目录移动携带事务归属标记，无法确定归属或出现冲突时停止并保留记录。
