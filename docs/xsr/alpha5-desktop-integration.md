# Alpha 4 后续：桌面集成与首次运行

状态：进行中。本文是验收清单，不代表功能已经完成。

## 交付顺序

1. Windows 输入设备：修正 digitizer 位标志；Raw Input 枚举键盘，失败不能写成 false。
2. 窗口：保留现有绘制区尺寸，外扩宿主；合成抗锯齿圆角与自绘阴影；启动/关闭遮罩连续收至图标后方。不得以全透明主窗口牺牲 DWM 动画。
3. 设置：重排全局设置列表；独立实例设置使用既有分层设置服务，明确继承与覆盖。
4. 文件交互：版本行双击打开目录；系统拖放保留 Ctrl/Shift/Alt 语义；导入先识别再确认，不能将未知文件直接执行。目录识别 Minecraft 根目录/实例，JAR 提供模组/核心/加载器选择，MRPACK/ZIP 交由整合包服务。
5. 任务泡泡：每个泡泡均有横向展开信息，隐藏项不占位置，动作和导航一致。
6. JVM：核对现有 IJvmHost 与独立 Jvm.Host 的职责；验证实际 Minecraft 启动、日志、退出、崩溃、取消与多实例隔离。
7. 首次运行：欢迎 → 数据存储位置 → 用户体验计划与遥测 → 结束。遥测默认关闭，可撤回；异常记录必须脱敏。
8. Cloudflare：在现有上级 Server Worker 中接入遥测 API，并连接已有更新流；完整验证签名、通道、平台与失败回退。
9. Patch：先确认 Java/C# 目标；冻结 HEAD/ARGS/TAIL/RETURN/REPLACE 的顺序、异常和返回语义，再实施生成器。不得把只能生成新代码的 source generator 宣称为任意现有方法重写器，不得使用 NativeAOT 不支持的运行时动态代码。

## 当前输入设备修正

Windows `SM_DIGITIZER` 的 READY 为 0x80，集成/外接触摸分别为
0x01/0x02，集成/外接笔分别为 0x04/0x08。MULTI_INPUT 本身不证明触摸存在。
键盘使用 `GetRawInputDeviceList` 的 RIM_TYPEKEYBOARD；枚举热插拔重试有界，
失败投影 TemporarilyUnavailable，不把 Windows 会话本身视为物理键盘。
形态推断复用同一探测；键盘未知时保守地不推断为无键盘掌机。

## 验收

每批独立提交并推送。涉及服务契约的批次补契约测试和架构检查；本机互操作
必须执行 NativeAOT 测试。视觉批次检查不同 DPI、最大化/还原、快速反向操作、
减弱动态效果。完成状态以真实验证结果为准。

## 泡泡呈现

任务、启动和进程泡泡共用 HoverExpand 横向弹簧呈现，静止为 48 DIP 图标圆，
展开向左且右侧锚点不动。任务展示数量、百分比和进度轨；进程展示实例名称与动作。
键盘焦点也可展开。纵向停靠仍按 48 DIP 高度排列，退出项立即释放位置。

## 关闭动画连续性

启动期间关闭以当前 mask 半径和图标缩放作为起点；取消旧图标轨道，避免两个图标叠加。
图标折叠同步收缩原生区域，最终为空区域；销毁前不得恢复完整窗口区域。
此项不等于完成抗锯齿或外扩阴影，后两项仍待合成层处理。
