PCL Nexa

为 Minecraft 重新打造的启动体验。

PCL Nexa 是 PCL N 2.0 的 Alpha 产品线。它不是一次简单换皮，而是从启动、下载、账号、更新到界面交互的完整重构，目标是让每天都会用到的操作更直接、更可靠。

名称仍处于过渡期

Alpha 阶段当前使用 “PCL Nexa”。Alpha 结束后，产品将正式更名为 “Nexa Launcher”。仓库、解决方案和部分内部标识会在合适的迁移阶段再逐步调整。

日常体验

把复杂的启动流程，重新变得简单。

2.0 的重点不是展示更多开关，而是把实例、Java、账号、资源和更新这些幕后工作交给启动器处理，让用户只面对真正需要做的选择。

启动 Minecraft

Alpha 意味着什么？

功能和数据兼容会持续收敛，但交互、页面完整度以及部分生态能力仍可能快速变化。它适合跟进 2.0 的演进和参与测试，不应该被理解为已经取代稳定的 1.4.x。

如果你只希望稳定地日常启动游戏，请继续把现有稳定版本作为主力；2.0 Alpha 更适合愿意测试新架构与新界面的用户。

为什么 2.0 不一样

技术变化，最终应该体现在使用体验上。

2.0 的底层采用全新的 XSR 架构、NativeAOT、UI.Next / PXML 与独立插件进程边界，但这些不是为了堆技术名词，而是服务于三个直接目标。

更直接

减少运行时反射和不必要的层层转发，让启动、状态更新和界面刷新拥有更明确的数据路径。

更可控

下载、更新、状态和插件边界都有更严格的契约，异常更容易被隔离，也更容易复现和验证。

更适合继续扩展

新页面、插件 SDK 与后续平台能力可以建立在清晰边界上，而不是继续增加旧架构的耦合。

FAQ

常见问题。

PCL Nexa 现在就是 Nexa Launcher 吗？

不是。PCL Nexa 是 2.0 Alpha 阶段的过渡名称；Alpha 结束后才正式使用 Nexa Launcher。

2.0 会直接替代 PCL N 1.4.x 吗？

目标是在完成迁移与切换门槛后由 2.0 接棒，但当前 Alpha 仍处于产品完成阶段。1.4.x 继续承担稳定产品线的角色。

旧版本能升级到 2.0 吗？

2.0 的更新策略明确支持 1.4.x → 2.0 的跨代升级。进入 2.0 后，更新系统不会主动提供回到 1.4.x 或更低 2.0 版本的降级。

为什么要重写这么多东西？

因为这次目标不仅是修几个页面，而是把运行时、业务能力、界面、插件边界和更新链路一起整理成长期可维护的基础。这样后续功能才能少依赖历史包袱。

我现在适合使用 Alpha 吗？

如果你愿意测试新功能、接受页面和行为仍在变化，并希望帮助发现问题，可以关注 Alpha；如果你只需要稳定启动游戏，现有稳定版本仍更合适。
