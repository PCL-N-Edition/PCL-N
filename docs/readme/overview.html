Alpha 期间继续使用 PCL Nexa。Alpha 结束后会正式改名为 Nexa Launcher。仓库和内部名称会在后面逐步调整。

日常使用

日常启动游戏，应该少操点心。

实例、Java、账号、资源和更新这些事情，能自动处理的就交给启动器。你只需要处理真正需要选择的部分。

▶

启动 Minecraft

启动器会找到本地实例，处理版本继承，选择合适的 Java，再准备资源和依赖。游戏启动后，它也会继续记录进程状态，方便排查崩溃。

查找实例选择 Java准备资源记录进程分析崩溃
⇩

下载中断了也能继续

下载中断后可以继续。大文件会分段下载。某个来源不可用时，启动器会尝试其他来源。

断点续传分段下载自动换源
↻

更新少折腾

启动器会先检查可用版本，再决定用完整包还是更小的补丁。下载完成后会验证文件，再开始安装。PCL N 1.4.x 也可以直接升级到 2.0。

检查版本→准备更新→下载→验证→安装

为什么要做 2.0

重做这些东西，是为了少出问题。

2.0 底层用了 XSR、NativeAOT、UI.Next 和 PXML。你不需要记这些名字。它们主要用来解决速度、稳定性和后续维护的问题。

少绕一层

启动和界面更新尽量走更直接的路径。少做不必要的中转。

出问题更好查

下载、更新和插件都有更清楚的边界。某一块出错时，更容易找到原因。

以后更好加功能

新页面和插件能力可以继续往上加，不用一直绕着旧代码改。

常见问题

PCL Nexa 现在就是 Nexa Launcher 吗？

不是。PCL Nexa 只是 2.0 Alpha 期间使用的名字。Alpha 结束后才会正式改名为 Nexa Launcher。

2.0 现在会取代 PCL N 1.4.x 吗？

还不会。Alpha 期间，PCL N 1.4.x 仍然是稳定版。等 2.0 做完并通过切换检查后，才会正式接替它。

PCL N 1.4.x 能升级到 2.0 吗？

可以。更新系统支持从 1.4.x 直接升级到 2.0。进入 2.0 后，启动器不会主动提供降级到 1.4.x 或更旧 2.0 版本的选项。

为什么这次要重写这么多？

旧架构已经越来越难继续改。2.0 选择一次把启动、界面、更新和插件这些基础重新整理好，后面做功能会轻松很多。

我现在适合用 Alpha 吗？

如果你想提前体验 2.0，也能接受页面和功能还会变化，可以试 Alpha。如果你只想稳定玩游戏，继续用稳定版更合适。
