# PCL N Edition 隐私保护协议

**版本号：** v0.1  
**更新日期：** 2026 年 7 月 28 日  
**生效日期：** 2026 年 7 月 28 日  
**个人信息处理者：** MUXUE1230（个人开发者）  
**隐私联系邮箱：** GitHub Issues（https://github.com/PCL-N-Edition/PCL-N/issues）

> 本文件为依据当前项目功能起草的协议草案。正式发布前，应由实际运营主体结合部署区域、第三方服务清单、数据保存期限和真实客户端行为进行法律与安全复核。

## 一、适用范围

1. 本协议说明 PCL N 官方客户端如何处理个人信息。
2. N Cloud、插件中心、在线账户、购买权益和发布者服务的信息处理，另见《N Cloud 隐私保护协议》。
3. 第三方插件、第三方认证服务和第三方下载平台可能有独立的隐私规则。除法律规定或者我们实际参与共同处理的情形外，其独立处理活动由相应主体负责。
4. 你自行编译或修改的非官方版本可能改变信息处理行为，不属于本协议能够控制的范围。

## 二、基本原则

我们按照合法、正当、必要、诚信、目的明确、最小范围和公开透明原则处理个人信息，并采取与风险相适应的安全措施。

## 三、本地处理的数据

下列数据通常保存在你的设备上，不会仅因使用本软件而自动上传：

| 数据类别 | 示例 | 用途 |
|---|---|---|
| 启动器配置 | 语言、主题、下载设置、Java 路径、启动参数 | 保存偏好并执行启动 |
| 实例信息 | Minecraft 版本、加载器、模组列表、实例路径 | 管理和启动游戏 |
| 本地账户资料 | 账户类型、角色名称、认证缓存、令牌 | 完成登录和启动 |
| 本地文件 | 存档、日志、截图、模组、资源包、配置 | 执行你主动选择的管理操作 |
| 运行日志 | 启动器和游戏错误、堆栈、时间、组件版本 | 本地诊断和故障排查 |
| 插件本地数据 | 插件配置、安装状态、权限决定 | 运行已安装插件 |

你主动导出、上传、提交诊断、开启云同步或交由第三方插件处理时，相关数据才会按对应功能发送至网络服务。

## 四、联网时可能处理的信息

### 1. 更新与资源下载

为检查更新、验证签名和下载资源，可能处理：

1. 客户端版本、操作系统和处理器架构；
2. 请求时间、目标资源、下载状态和错误码；
3. 网络请求通常附带的 IP 地址、协议和基础设备信息；
4. 更新包、资源文件的哈希及签名验证结果。

### 2. Microsoft、Minecraft 和第三方认证

当你选择相应登录方式时，可能处理：

1. 账户标识符、角色名称、头像或皮肤信息；
2. OAuth 授权码、访问令牌、刷新令牌或第三方认证令牌；
3. Minecraft 所有权、角色 UUID 和必要的 Xbox/Minecraft 档案信息；
4. 你输入的第三方认证服务器地址和用户名。

认证令牌属于高风险身份鉴别信息。我们仅在登录、刷新会话和启动游戏所必需的范围内处理，不会向普通插件公开 Microsoft、Xbox 或 Minecraft 令牌。

### 3. 错误报告和诊断

当你主动提交错误报告，或者在产品中明确启用诊断上传时，可能包含：

1. PCL N 版本、操作系统、架构、运行时和组件版本；
2. 异常类型、堆栈、时间、操作步骤和性能信息；
3. 经你选择附带的启动器日志或游戏日志；
4. 网络地址和报告关联标识。

日志可能意外包含用户名、文件路径、服务器地址或模组信息。提交前应允许你预览或提示你移除密码、令牌及其他敏感内容。

### 4. 插件

插件仅应在其声明并获得授权的范围内访问服务和数据。插件自行访问网络、读取文件或处理个人信息时，应由插件发布者另行说明目的、范围、保存期限和联系方式。

## 五、设备端保存

1. 账户和配置可能保存在应用数据目录、配置文件、系统凭据存储或由操作系统账户权限保护的本地位置。
2. 在操作系统支持且实现条件允许时，我们应优先使用系统凭据库或等效安全机制保存认证凭据。
3. 若当前平台无法提供相同级别的安全存储，我们会尽量采用加密、权限限制、缩短有效期等措施，并在必要时向你提示风险。
4. 卸载软件不一定自动删除所有实例、存档、缓存或配置。你可以使用产品提供的清理功能或手动删除对应目录。

## 六、第三方服务

根据你使用的功能，数据可能直接发送至：

1. Microsoft、Xbox Network 和 Minecraft 服务，用于正版登录、所有权验证和游戏档案；
2. 你选择的 Authlib-Injector、LittleSkin 或其他第三方认证服务；
3. Mojang、Modrinth、CurseForge、GitHub 或其他资源和更新提供者；
4. 内容分发、崩溃诊断或网络基础设施服务商；
5. N Cloud。启用时依照 N Cloud 隐私协议处理。

第三方服务可能根据其自身规则记录 IP 地址、设备信息和使用情况。请同时阅读相应服务的隐私政策。

## 七、共享、委托和转移

1. 我们不会以出售个人信息为目的向第三方提供你的个人信息。
2. 为提供托管、认证、存储、诊断、安全防护或客户支持，我们可能委托服务商处理必要信息，并通过合同、安全配置和权限控制约束其处理活动。
3. 发生合并、分立、重组、资产转让或运营主体变更时，如涉及个人信息转移，我们会依法告知接收方信息，并要求其继续受本协议约束；处理目的或方式发生变化时，将依法重新取得同意。
4. 根据法律法规、诉讼程序或主管机关依法提出的要求，我们可能提供必要信息。

## 八、跨境处理

Microsoft、GitHub 及部分基础设施或第三方服务可能由境外主体运营。需要向境外提供个人信息时，我们会依法：

1. 告知境外接收方名称或类型、联系方式、处理目的、方式、信息种类及权利行使方式；
2. 在需要时取得你的单独同意；
3. 进行个人信息保护影响评估；
4. 根据适用门槛履行标准合同、认证、安全评估或其他法定程序；
5. 采取加密、最小化和访问控制等保护措施。

未经完成所需合规程序，我们不应擅自扩大跨境个人信息处理范围。

## 九、保存期限

1. 本地配置、实例和日志保存至你删除、重置或卸载相关数据。
2. 认证令牌保存至退出登录、令牌失效、账户解绑或不再需要时；法律或安全要求另有规定的除外。
3. 在线诊断数据仅保存实现故障分析和安全目的所需的最短时间，具体期限为至多 90 日，或完成故障分析后尽快删除。
4. 网络和安全日志按照法律要求保存，通常不少于六个月；超过必要期限后删除或匿名化。
5. 备份中的数据会在合理备份周期内覆盖或清除。

## 十、安全措施

我们根据实际风险采用传输加密、签名验证、哈希校验、权限隔离、最小权限、凭据保护、漏洞修复和安全事件响应等措施。但任何系统都无法保证绝对安全，你也应及时更新软件、保护操作系统账户并避免安装来源不明的插件。

## 十一、你的权利

你可以依法请求：

1. 查阅、复制和更正我们处理的个人信息；
2. 删除不再必要、违法处理或依法应删除的信息；
3. 撤回基于同意开展的处理；
4. 注销或解绑在线账户和设备；
5. 获取个人信息处理规则的解释；
6. 对拒绝请求的决定进行申诉。

本地数据可以通过软件设置或文件系统直接管理。涉及在线服务的请求可发送至GitHub Issues（https://github.com/PCL-N-Edition/PCL-N/issues）。为保护账户安全，我们可能要求进行必要身份验证。

## 十二、未成年人

1. 本软件面向包含未成年人的 Minecraft 用户群体，但不以收集儿童个人信息为主要目的。
2. 不满十四周岁的儿童启用需要联网账户、云服务或诊断上传的功能前，应取得监护人同意。
3. 对我们明知属于不满十四周岁儿童的个人信息，将制定专门规则并采取严格保护措施。
4. 监护人可以联系我们查阅、更正或删除儿童信息。

## 十三、协议更新和联系

1. 处理目的、信息种类、第三方接收方或用户权利发生重大变化时，我们会以显著方式通知。
2. 对依法需要重新同意的处理，我们会再次征得同意。
3. 隐私问题、投诉或权利请求请联系：GitHub Issues（https://github.com/PCL-N-Edition/PCL-N/issues）。
4. 一般请求将在法律规定期限内处理；复杂请求会说明原因和预计处理安排。
