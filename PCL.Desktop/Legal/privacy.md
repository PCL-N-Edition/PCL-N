# PCL N Edition 隐私保护协议

**版本号：** v0.2  
**更新日期：** 2026 年 7 月 28 日  
**生效日期：** 2026 年 7 月 28 日  
**个人信息处理者：** MUXUE1230（个人开发者）  
**联系方式：** GitHub Issues（https://github.com/PCL-N-Edition/PCL-N/issues）

## 一、适用范围

1. 本协议说明 **PCL N 官方客户端** 如何处理个人信息。
2. N Cloud、插件中心、在线账户、设备授权、购买权益与发布者服务另见 **《N Cloud 隐私保护协议》**。
3. 第三方插件、第三方认证与下载平台可能有独立规则；除我们共同处理或法律另有规定外，由相应主体负责。
4. 你自行编译或修改的非官方版本可能改变处理行为，不在本协议可控范围内。

## 二、基本原则

我们按照合法、正当、必要、诚信、目的明确、最小范围与公开透明原则处理个人信息，并采取与风险相适应的安全措施。

**首次启动客户端时，我们会提示你阅读并同意本协议及用户服务协议；不同意则无法继续使用官方客户端功能。**

## 三、本地处理的数据

下列数据通常保存在你的设备本地，不会仅因启动本软件而自动上传：

| 数据类别 | 示例 | 用途 |
|---|---|---|
| 启动器配置 | 语言、主题、下载设置、Java 路径、启动参数、协议同意版本 | 保存偏好并执行启动 |
| 实例信息 | 版本、加载器、模组列表、路径 | 管理与启动游戏 |
| 本地账户资料 | 账户类型、角色名、认证缓存/令牌 | 登录与启动 |
| 本地文件 | 存档、日志、截图、模组、资源包 | 你主动发起的管理操作 |
| 运行日志 | 错误、堆栈、时间、组件版本 | 本地诊断 |
| 插件本地数据 | 配置、安装状态、权限决定 | 运行已安装插件（sidecar） |

仅在你主动导出、提交反馈/诊断、开启云同步、连接 N Cloud 或授权插件联网时，相关数据才会按对应功能发送至网络。

## 四、联网时可能处理的信息

### 1. 更新、公告与资源下载

可能处理：客户端版本、操作系统与架构、请求时间、目标资源、下载状态与错误码、IP 等网络基础信息、文件哈希与签名验证结果；以及用于展示的启动器公告元数据。

### 2. Microsoft、Minecraft 与第三方认证

当你选择相应登录方式时，可能处理：账户标识、角色名/头像/皮肤、OAuth 授权码与令牌、Minecraft 所有权与角色 UUID、你输入的第三方认证服务器地址与用户名等。

令牌属于高风险身份鉴别信息，仅在登录、刷新会话与启动所必需范围内处理，**不会向普通插件公开** Microsoft / Xbox / Minecraft 令牌。

### 3. 反馈与诊断

当你主动通过客户端反馈入口提交 Issue，或明确启用诊断上传时，可能包含：版本与运行环境、异常类型与堆栈、你填写的标题/描述、可选日志，以及用于关联的提交记录。内容可能经 N Cloud 转发至 GitHub Issues，并按类型附加标签。

提交前应避免写入密码、令牌、完整账户机密信息。

### 4. 插件

插件仅应在声明并获授权的范围内访问服务与数据。插件自行联网或处理个人信息时，由插件发布者另行说明。

### 5. N Cloud

启用在线账户、设备配对、云端偏好/插件数据、插件市场等功能时，处理规则以《N Cloud 隐私保护协议》为准。

## 五、设备端保存

1. 配置与账户数据可能位于应用数据目录、配置文件或系统凭据存储。
2. 在操作系统支持时，应优先使用系统凭据库或等效机制保存认证凭据。
3. 卸载本软件不一定自动删除全部实例、存档与缓存，你可手动清理。

## 六、第三方服务

根据你使用的功能，数据可能直接发往：

1. Microsoft / Xbox / Minecraft 服务（正版登录与档案）；
2. 你选择的 Authlib-Injector、LittleSkin 等认证服务；
3. Mojang、Modrinth、CurseForge、GitHub 等资源/更新来源；
4. CDN 或网络基础设施；
5. N Cloud（Supabase 认证与业务 API 等，详见 N Cloud 隐私协议）。

## 七、共享、委托与转移

1. 我们不以出售个人信息为目的向第三方提供信息。
2. 为托管、认证、存储、诊断、安全等需要，可能委托服务商处理必要信息，并约束其用途。
3. 依法配合监管或司法机关要求时，可能提供必要信息。
4. 运营主体变更涉及个人信息转移时，将依法告知并要求接收方继续受本协议约束。

## 八、跨境处理

Microsoft、GitHub 及部分基础设施可能由境外主体运营。涉及向境外提供个人信息时，我们将依法告知接收方情况、取得所需同意，并采取加密、最小化与访问控制等措施。具体出境路径以实际部署与 N Cloud 公示为准。

## 九、保存期限

1. 本地配置、实例与日志：至你删除、重置或卸载相关数据。
2. 认证令牌：至退出登录、失效、解绑或不再需要时（法律另有要求除外）。
3. 经你提交的在线反馈/诊断关联数据：以实现故障分析、安全与工单处理为限，通常不超过 **90 日**，或处理完成后尽快删除（GitHub 公开 Issue 受其平台规则约束）。
4. 网络与安全日志：按法律要求保存（通常不少于六个月），超时删除或匿名化。

## 十、安全措施

我们根据实际风险采用传输加密、签名与哈希校验、权限隔离、凭据保护、漏洞修复等措施。任何系统均无法保证绝对安全；你也应及时更新软件、保护系统账户，并避免安装来源不明的插件。

## 十一、你的权利

你可以依法请求查阅、复制、更正、删除、撤回同意、注销/解绑在线账户与设备，以及对处理规则获得解释。本地数据可通过设置或文件系统管理；涉及在线服务的请求可通过 GitHub Issues 提出。为防冒用，我们可能要求验证账户控制权。

## 十二、未成年人

1. 本软件面向含未成年人的 Minecraft 用户，但不以收集儿童信息为主要目的。
2. 不满十四周岁的儿童启用需联网账户、云服务或诊断上传的功能前，应取得监护人同意。
3. 监护人可联系我们查阅、更正或删除儿童信息。

## 十三、协议更新与联系

1. 处理目的、信息种类或第三方接收方发生重大变化时，我们将以显著方式通知，并可能要求你重新确认协议版本。
2. 隐私问题、投诉或权利请求：GitHub Issues（https://github.com/PCL-N-Edition/PCL-N/issues）。
3. 一般请求在法定期限内处理；复杂请求会说明原因与安排。
